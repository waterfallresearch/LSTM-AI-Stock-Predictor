# Point-in-time earnings data gate

Test whether original quarterly EPS actuals, release timing, and dated consensus can support both earnings surprise and revisions for the historical S&P 500. The data gate uses no labels or returns. The strategy trial count is 49 and the 2025 confirmation is sealed.

- Use the frozen 2016–2024 month-end CRSP security roster, SHA-256 `00322c50661b320f9db84b21b9e6d14fc75f174126030c6de727aa6c902adf56`, with historical members and no availability filter. Preserve issuer and security identifiers separately. Apply the December 31, 2024 market-close cutoff and the prior-session close cutoff for each signal.
- Prefer LSEG. Require actual and consensus to match on dated issuer, fiscal quarter, currency, split basis, EPS definition and units. Verify the original release and first vendor availability independently of the currently displayed actual. Date-only vendor snapshots become available at end of day. Require both vendor availability and authenticated public release before the first usable exchange open. Keep later corrections in separate vintages and quarantine ambiguous links and conflicting observations.
- Use the latest observable quarterly actual and the last matching consensus snapshot observable by the close of the exchange session strictly preceding the release date in Eastern time. Define raw surprise as actual less that consensus. Define revision as the change in that same consensus series versus its latest dated snapshot observable by the close 21 exchange sessions before the pre-release cutoff. Require the recent consensus snapshot to be no more than five sessions old at its cutoff and the comparison snapshot no more than five sessions old at its cutoff. Keep missing observations missing. Apply a 120-calendar-day maximum release age at signal formation.
- Use WRDS EPS history as an independent check or fallback only under the same definitions, provenance and timing rules. Compustat announcement dates can corroborate a calendar date. A date alone cannot certify an intraday release or historical consensus. Report LSEG-only and combined coverage, source disagreements and gap recovery.
- Require both feature values for at least 80% of security-months overall, 70% each year, 60% in each prior-session size tercile, and 60% for securities delisting within 12 months on fully observed windows. Carry forward the conservative unknown-size denominator treatment. Report coverage for each feature, month, source and failure reason.
- Before reading sampled values, freeze a stratified audit of 120 admitted events and 40 rejected events using seed 20261122. Include revisions, fiscal transitions, splits, correction vintages, after-hours releases and delisted issuers where present. Require exact agreement on identity, basis, periods and timing and agreement within source rounding on amounts. If fallback determines a pass, verify at least 30 fallback events with zero unresolved discrepancies. Insufficient source access leaves the corresponding coverage unmeasured.
- After a pass and independent review, preregister one paired predictive experiment for surprise and revisions jointly against the existing price-based baseline, using matched eligibility, folds, execution and costs. Opening the confirmation period requires separate authorization.
