# Portfolio breadth preregistration

Frozen before any breadth development outcomes were generated. The existing head-to-head results are development evidence. No reserved 2025 observations may enter this study.

The primary hypothesis is that a wider basket improves annualized net Sharpe by at least 0.20 relative to five names, because spreading the same weak rank across more names can reduce single-name risk. The null is no positive Sharpe improvement. Start with $1M. At each month end from January 2016 through November 2024, rank point-in-time S&P 500 members on observed total-return closes TR[t-21]/TR[t-126]-1. Apply the existing causal spike filter and $5 price floor using data through the preceding session. Break ties by ascending ISIN. Include only names with both observed lagged endpoints and current membership. Select up to five in the control, and min(100, ceil(eligible/5)) in the broad arm. No fallback names or leverage. Allocate 1/5 per selected control name, and equal weight across the registered broad selection count. Empty selections target cash.

At the next open, snapshot equity using the open or the last known adjusted-for-split mark for halted holdings. Size the target from that equity. Execute sells before buys, in ISIN order for sells and in signal rank order for buys. Trim or add only the difference. Post no new buy after a missing next open. Carry pending trims and exits as residual share orders until a valid open or settlement; replace those quantities on the next rebalance. Cap discretionary trades per side at 5% of prior ADV shares, cancel any buy remainder and defer sell remainders. Missing ADV blocks discretionary fills. Verified corporate settlements are mandatory. Apply splits and dividends before trading. Mark remaining positions at the final 2024 close, with no terminal liquidation.

Charge 1 bp commission per side, half of prior available trailing quoted spread or the documented fallback, square-root impact k=1, and dated statutory sell fees. Stress doubles commission and spread, and uses k=2. Gross is a separately labelled zero-cost rerun holding the trading rules fixed. Reconcile daily cash, marked holdings and equity. The top-three diagnostic removes each arm's largest positive realized exit P&Ls from equity starting on the respective exit dates without resimulating reinvestment.

Use identical daily return dates. Primary statistic is broad minus five-name annualized net Sharpe. Require point difference >=0.20 and the 5th percentile of 5,000 paired noncircular 20-session moving-block draws (seed 20261121) above zero. Require broad Deflated Sharpe >=0.95 using the 45 prior Sharpes and the two new arms, with positive broad-minus-control Sharpe in both stress and top-three diagnostics. Report two-sided interval, ranked Spearman IC against next-open-to-following-rebalance-open total return, both benchmarks, net and gross risk and returns, costs, turnover, exposure, capacity restrictions and annual results. Exclude IC outcomes that cannot be formed on executable opens inside development. The equal-weight eligible universe is a frictionless contextual return series. SPY total return is contextual. The two scored arms raise N to 47. Diagnostics do not select a configuration. Failure stops promotion. Any redesigned recipe is a new trial.
